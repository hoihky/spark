CesiumMan (CesiumMan.glb)

Khronos sample humanoid (single walk cycle).

Clip index glTF name Duration (approx.) Character3DAnimFsm resolve
0 (empty) ~1.0 s Walk (only clip; also used as idle/run fallback)

There is no separate idle, run, or attack clip. ConfigureLocomotionFromSkeleton maps: - Idle → clip 0 (no idle name match; falls back to walk clip index) - Walk → clip 0 - Run → kInvalidAnimClipIndex (no run match — FSM reuses walk clip at runtime when sprinting)

Joint highlights: Skeleton_torso_joint_1, torso_joint_3 — no hip substring; root motion uses pattern fallback or explicit joint index.

Events: CesiumMan.spark-anim-events.json — unnamed walk clip matched by sidecar name Walk: - active_start @ 0.25 s - active_end @ 0.55 s

walkClipIndex: 0.

Demo wiring: Character camera M key switches to CesiumMan; attack hint resolves to walk substring (clip 0).

Clip name conventions (engine)

ResolveLocomotionClipsFromSkeleton (LocomotionClipSet.cpp) resolves clips by case-insensitive exact name or substring:

Role Name patterns tried
Idle idle, survey, rest, stand
Walk walk
Run run, jog, sprint
Attack attack, punch, kick, shoot
Hurt hurt, hit, damage, pain

When adding new sample assets, prefer these names so Character3DAnimFsmComponent::ConfigureLocomotionFromSkeleton works without manual clip indices.
