# 3D animation sample assets

Reference skinned glTF characters shipped with Spark for demos, tests, and export validation. See also [`BLENDER_GLTF_ANIMATION_EXPORT.md`](BLENDER_GLTF_ANIMATION_EXPORT.md) for artist rules.

## Summary

| Asset | Path | Joints | Clips | FSM resolve | Primary use |
|-------|------|--------|-------|-------------|-------------|
| **Fox** | `assets/models/Fox.glb` | 24 | 3 | idle/walk/run + attack proxy | Quadruped locomotion, melee events on `Run` |
| **CesiumMan** | `assets/models/CesiumMan.glb` | 19 | 1 | walk only (unnamed clip) | Khronos humanoid baseline, walk-cycle combat demo |
| **SparkHumanoid** | `assets/models/SparkHumanoid.glb` | 8 | 4 | idle/walk/run/attack | Minimal biped with all locomotion + combat clip names |

Sidecar event files (optional): `*.spark-anim-events.json` next to each `.glb`.

## Fox (`Fox.glb`)

Khronos sample quadruped. Default avatar in **Character camera** and **ThreeDDemo**.

| Clip index | glTF name | Duration (approx.) | `Character3DAnimFsm` resolve |
|------------|-----------|--------------------|------------------------------|
| 0 | `Survey` | ~2.0 s | **Idle** (name contains `survey`) |
| 1 | `Walk` | ~1.0 s | **Walk** |
| 2 | `Run` | ~0.5 s | **Run**; also used as **attack proxy** in Character camera demo (`F` key) |

**Joint highlights:** `_rootJoint` → `b_Hip_01` (hips). Root-motion pattern resolver matches `hip`.

**Events:** `Fox.spark-anim-events.json` — `Run` clip:
- `footstep` @ 0.10 s
- `active_start` @ 0.18 s
- `active_end` @ 0.42 s

**`walkClipIndex`:** `1` (first clip whose name contains `walk`).

**Demo wiring:** Character camera uses Fox by default; melee hit window driven by `Run` events; attachment socket searches `head` then `hip`.

## CesiumMan (`CesiumMan.glb`)

Khronos sample humanoid (single walk cycle).

| Clip index | glTF name | Duration (approx.) | `Character3DAnimFsm` resolve |
|------------|-----------|--------------------|------------------------------|
| 0 | *(empty)* | ~1.0 s | **Walk** (only clip; also used as idle/run fallback) |

There is no separate idle, run, or attack clip. `ConfigureLocomotionFromSkeleton` maps:
- **Idle** → clip 0 (no `idle` name match; falls back to walk clip index)
- **Walk** → clip 0
- **Run** → `kInvalidAnimClipIndex` (no `run` match — FSM reuses walk clip at runtime when sprinting)

**Joint highlights:** `Skeleton_torso_joint_1`, `torso_joint_3` — no `hip` substring; root motion uses pattern fallback or explicit joint index.

**Events:** `CesiumMan.spark-anim-events.json` — unnamed walk clip matched by sidecar name `Walk`:
- `active_start` @ 0.25 s
- `active_end` @ 0.55 s

**`walkClipIndex`:** `0`.

**Demo wiring:** Character camera **M** key switches to CesiumMan; attack hint resolves to `walk` substring (clip 0).

## SparkHumanoid (`SparkHumanoid.glb`)

Minimal biped generated by [`tools/generate_spark_humanoid.py`](../tools/generate_spark_humanoid.py). Intended for CI, FSM smoke tests, and documentation — not production art.

| Clip index | glTF name | Duration | `Character3DAnimFsm` resolve |
|------------|-----------|----------|------------------------------|
| 0 | `Idle` | 2.0 s | **Idle** |
| 1 | `Walk` | 1.0 s | **Walk** |
| 2 | `Run` | 0.6 s | **Run** |
| 3 | `Attack` | 0.8 s | **Attack** (Once) |

**Joints (8):** `root` → `hips` → `spine` / `leg_l` / `leg_r`; `spine` → `head` / `arm_l` / `arm_r`.

**`hips`** joint satisfies root-motion and attachment name patterns.

**Events:** `SparkHumanoid.spark-anim-events.json` — `Attack` clip:
- `active_start` @ 0.20 s
- `active_end` @ 0.50 s

**Regenerate:**

```bash
python3 tools/generate_spark_humanoid.py
```

**Load:**

```cpp
SkinnedGltfAsset humanoid = world.LoadSkinnedGltf("assets/models/SparkHumanoid.glb");
```

## Clip name conventions (engine)

`ResolveLocomotionClipsFromSkeleton` (`LocomotionClipSet.cpp`) resolves clips by **case-insensitive** exact name or **substring**:

| Role | Name patterns tried |
|------|---------------------|
| Idle | `idle`, `survey`, `rest`, `stand` |
| Walk | `walk` |
| Run | `run`, `jog`, `sprint` |
| Attack | `attack`, `punch`, `kick`, `shoot` |
| Hurt | `hurt`, `hit`, `damage`, `pain` |

When adding new sample assets, prefer these names so `Character3DAnimFsmComponent::ConfigureLocomotionFromSkeleton` works without manual clip indices.
